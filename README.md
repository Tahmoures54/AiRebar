\# AI Rebar – Intelligent Bar Bending Schedule \& Optimization



\*\*AI Rebar\*\* is a professional desktop application for civil/structural engineers and rebar detailers. It provides a complete workflow for creating bar bending schedules (BBS), optimizing cutting patterns, managing scrap inventory, and exporting reports in Excel, PDF, and HTML formats.



!\[AI Rebar Screenshot](screenshot.png) <!-- You can add a screenshot later -->



\## Features



\- \*\*Project Management\*\*  

&nbsp; Create and manage multiple projects; each stores its own listofers and rebars.



\- \*\*Smart Rebar Input\*\*  

&nbsp; Two dialog modes: a full parametric input dialog and a “Quick Add” for straight bars.



\- \*\*Shape Library\*\*  

&nbsp; Supports all common BS 8666 shapes (and custom ones). Built‑in length calculation and shape preview.



\- \*\*BBS Treeview\*\*  

&nbsp; Interactive table with dynamic filtering, column sorting, and right‑click context menus (Edit, Duplicate, Copy, Delete).



\- \*\*Cutting Optimizer\*\*  

&nbsp; Uses linear programming (PuLP) to minimize waste. Reuses scrap pieces from the Smart Scrap Bank.



\- \*\*Scrap Bank\*\*  

&nbsp; Keeps track of usable off‑cuts. Scraps are automatically reused in cutting plans.



\- \*\*Professional Reports\*\*  

&nbsp; Export to \*\*HTML\*\* (with embedded SVG shape diagrams), \*\*Excel\*\*, and \*\*PDF\*\*.



\- \*\*Themes\*\*  

&nbsp; Switch between Light, Dark, and Blue themes. Theme choice is saved automatically.



\- \*\*Lap Splice Calculator\*\*  

&nbsp; Quick ACI‑based lap length calculator.



\- \*\*Trial Period\*\*  

&nbsp; 30‑day full‑featured trial, with easy contact option for purchase.
