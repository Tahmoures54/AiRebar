# RebarAgent – Intelligent Bar Bending Schedule & Optimization

Desktop BBS + cutting optimization for civil engineers. Offline-friendly, Iran-first, multi-standard shapes, smart inventory, Agent Insights.

## Quick start
```bash
git clone https://github.com/Tahmoures54/AiRebar.git RebarAgent
cd RebarAgent
pip install -r requirements.txt
python main.py
```

## Key features
- Projects, listofers, parametric rebars, multi-standard shapes
- Cutting optimizer (multi-stock, kerf, scrap reuse, confirm + inventory rollback)
- Smart stock advisor, sample project, Excel import
- EN/FA i18n, license plans, WhatsApp purchase (+989160684552)
- Excel / PDF / HTML / BVBS export
