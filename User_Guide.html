⚙️ An Engine That Sees the Whole Project at Once

The mathematical core of AI Rebar solves the cutting problem using Operations Research algorithms (MILP) and Column Generation. Instead of looking at each bar in isolation, it considers every piece and every leftover simultaneously and finds the best arrangement.

🧠 Set It Once – Always Optimal
Every time you open the cutting plan, the engine resolves the problem based on the latest scraps and stock levels. Even with dozens of diameters and hundreds of pieces, the answer is precise and free of human error.
♻️ Yesterday's Scraps Are Today's Gold
The software keeps a smart scrap bank. When you cut new bars, leftover pieces are saved automatically, and the next plan will consume them first – without you lifting a finger.
📦 Smart Down to the Last Bar in Stock
If you've recorded your full-bar inventory, the optimizer can limit itself to exactly what you have on hand. If the stock is insufficient, it warns you so you can order more or adjust the plan.

📖 What Happens When You Click "Cutting Plan"?

1 The software reads every piece in your project, all existing scraps, and your current stock levels.
2 The problem is translated into a mathematical model (MILP): "Which piece goes on which bar to minimize total waste?"
3 Smart column generation builds only the useful cutting patterns – the algorithm doesn't wander aimlessly.
4 The final answer is ready: how many bars, the cut order, the exact waste amount, and which scraps were used today.

All of this happens in the background without your intervention. The result? A clean cutting plan, a print-ready BBS report, and scraps automatically banked for the next job.

📈 Three Clicks to Your First Cutting Plan

1
Set Project Info
Go to Settings ⚙️ → Project Info and enter your project name and client. This becomes the default for all new positions.
2

Click the 📌 New Pos button (or Ctrl+N). Select shape, dimensions, listofer number, and quantity. The listofer is created automatically if it doesn't exist.

Click 🧠 Cutting Plan. The optimizer runs and a detailed plan with waste analysis appears. You can filter by listofer directly from the Listofer Summary panel.

🛠️ Troubleshooting

Optimization takes too long
For projects with more than 120 pieces of a single diameter, the engine switches to a faster heuristic. You can also limit stock usage or increase the time limit in the settings.
Error "PuLP not installed"
The cutting optimizer requires the PuLP library. Please install it using pip install pulp and restart the application.
Preview not showing
Ensure you have selected a valid shape and entered numeric dimensions. If the preview remains blank, check that the drawing module is correctly imported.
License activation fails
Make sure you have copied the entire activation key and that your Machine ID matches the one used during purchase. Contact support if the problem persists.
Project not loading / "No project" message
Open Settings (⚙️) and fill in a project name under Project Info. The application will automatically create and activate that project on next launch.
